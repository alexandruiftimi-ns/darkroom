# Art / Gallery

**Idea:** the work is the interface. Everything else recedes to captions and a quiet frame.
**Use for:** artists, photographers, galleries, museums, architects, portfolios.

## Colour — monochrome
White, off-white or deep grey walls; text ink; no accent or a single functional one. Never tint the UI toward the artwork's colours — let the work own colour.

## Type
Instrument Sans + Instrument Serif, Space Grotesk, Newsreader, Hanken Grotesk. Small, precise captions (title, year, medium, dimensions) like wall labels.
Never: display type that competes with the work.

## Layout
Work at maximum size the viewport allows; captions adjacent, consistent position; index view (grid/list toggle) + single-work view; sequence matters (curation).

## Imagery
Accurate colour, correct crops (never crop artworks without the artist's consent), high-res zoom, installation views.

## Motion
Signature: work enlarges into full bleed / view transition from grid to single. Keyboard arrows between works.

## Switches
eyebrow OFF · tracked-caps SPARING (wall-label style) · index-numerals SPARING (catalogue numbers if real) · hairlines SPARING · cards OFF · glass OFF · gradients OFF · mono-labels SPARING (catalogue data) · centred-layout ON · marquee OFF · custom-cursor SPARING · full-bleed-imagery ON · script-lettering OFF

## Must-have
Alt text that describes the work; credits and rights; enquiry path; image protection policy stated (not right-click hacks).

## Never
Autoplay slideshows, heavy frames/shadows around works, watermarks across the work.

## Image prompt seed
"minimal gallery website, single artwork displayed large on <wall colour> ground, small precise caption typography, vast negative space, museum wall-label feel, no decoration"
