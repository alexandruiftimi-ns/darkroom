# Modern

**Idea:** clarity and precision; the product's real interface or work is the hero, the page responds instantly.
**Use for:** SaaS, developer tools, studios, startups, apps. **Not for:** heritage or sensory brands.

## Colour — disciplined
Light or dark from the use scene. Neutral ramp (4–6 steps), one brand accent with hover/active steps, semantic state colours only where needed. Avoid violet→blue gradients as identity.

## Type
One family is enough: Inter Tight / Inter, Geist, Hanken Grotesk, Instrument Sans, Figtree. Optional second: a mono (Geist Mono, JetBrains Mono) **only** for real code/data. Scale with clear jumps; headings 600–700 or a light display weight — pick one.
Never: Inter as display at default tracking with nothing else; three weights of grey text.

## Layout
12-col grid, left-aligned headings, real product screenshots/fragments built as live UI, sections that alternate composition (not three identical card rows).

## Imagery
Real UI with real data, crisp diagrams, product photography if hardware. No fake dashboards of grey bars.

## Motion
Signature: UI that responds (instant hover, state transitions 150–250 ms), one product demo sequence. No fade-up on every block.

## Switches
eyebrow OFF · tracked-caps OFF · index-numerals SPARING (real steps only) · hairlines SPARING · cards SPARING (varied, purposeful) · glass OFF · gradients OFF · mono-labels OFF (mono for code only) · centred-layout SPARING (one moment) · marquee OFF · custom-cursor OFF · full-bleed-imagery SPARING · script-lettering OFF

## Must-have
Pricing clarity, docs/login paths, keyboard-perfect, fast (< 2.5 s LCP measured).

## Never
Invented logo walls, "10,000+ teams", bento grid as the only idea, "Get started" on every button.

## Image prompt seed
"clean product marketing page, real software interface fragment cropped large, neutral palette with one <accent> accent, precise grid, crisp shadows, no gradients, no glass"
