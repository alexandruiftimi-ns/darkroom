# Editorial / News

**Idea:** information architecture is the design. Hierarchy, rhythm and typography let readers triage fast and then read deeply.
**Use for:** news, magazines, journals, reports, long-form, newsletters. **Not for:** single-product launches.

## Colour — monochrome
Ink on paper (or paper on ink), one functional accent for links/section flags/breaking. Photography supplies colour.

## Type
Text serif: Source Serif 4, Newsreader, Literata, Merriweather. Display: Fraunces, Newsreader Display, Playfair Display (careful, overused) or a strong grotesk (Public Sans, IBM Plex Sans). Sans for UI/meta: Public Sans, Inter, IBM Plex Sans. Superfamily pairing (Plex Serif + Plex Sans) is ideal. Defined roles: kicker, headline, deck, byline, body, caption.
Never: display faces for body, measure > 75ch, justified text on mobile.

## Layout
Hierarchical grid (lead story, secondaries, rivers); clear section fronts; density is allowed **with** structure. Article pages: one column, 60–70ch, generous leading, pull quotes sparingly.

## Imagery
Real photojournalism with captions and credits; charts that state one finding (one finding per chart; label the data directly; colour-blind-safe palette).

## Motion
Almost none. Sticky headers, progress bars on long reads; scrollytelling only for special features.

## Switches
eyebrow ON (section kickers carry information) · tracked-caps SPARING · index-numerals SPARING (lists, rankings) · hairlines ON (column rules) · cards SPARING · glass OFF · gradients OFF · mono-labels OFF · centred-layout OFF · marquee OFF (tickers only for real live data) · custom-cursor OFF · full-bleed-imagery SPARING · script-lettering OFF

## Must-have
Dates, bylines, corrections policy, accessible tables, ad slots that don't shift layout (CLS), AI-generated images labelled.

## Never
Infinite autoplay video, interstitials before content, clickbait typographic tricks.

"newspaper front page website, strong typographic hierarchy, serif headlines, column grid with hairline rules, black ink on off-white, one red section accent, real photojournalism thumbnails"
