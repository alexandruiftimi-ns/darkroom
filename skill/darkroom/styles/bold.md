# Bold

**Idea:** a poster wall. Huge type or whole fields of colour, very few elements, hard confident cuts.
**Use for:** campaigns, sport, music, festivals, agencies, launches that must shout. **Not for:** trust-sensitive or reading-heavy sites.

## Colour — expressive
2–3 saturated hues each owning whole sections, plus black/white. One dominant per viewport. Contrast always passes (big type helps, but check).

## Type
Display: Anton, Archivo (Black/Expanded), Bricolage Grotesque, Big Shoulders Display, Bebas Neue (sparingly). Text: Archivo, Inter, Work Sans. Display at 10–20vw is normal; tight leading 0.85–0.95; uppercase allowed for display.
Never: two loud display faces; body text in the display face.

## Layout
Type as image; full-bleed colour blocks; asymmetric crops; very short copy; one CTA style repeated.

## Imagery
High-contrast photography, cut-outs, duotones in the palette, motion blur used deliberately.

## Motion
Signature: hard cuts between colour fields, scroll-scaled type, marquee (one, meaningful). Fast, decisive (200–400 ms), no floaty easing.

## Switches
eyebrow OFF · tracked-caps SPARING · index-numerals SPARING · hairlines OFF · cards OFF · glass OFF · gradients OFF (flat fields) · mono-labels OFF · centred-layout ON (allowed) · marquee SPARING (one) · custom-cursor SPARING · full-bleed-imagery ON · script-lettering SPARING

## Must-have
Readable body at normal size beneath the shouting; reduced motion stops marquees; contrast checked per colour field.

## Never
Hardline brutalism by costume (zero-blur offset shadows) unless the world is actually neo-brutalist; five colours in one viewport.

## Image prompt seed
"bold poster-style website, giant <display face description> headline filling the frame, flat <colour> field, one high-contrast cut-out photograph, minimal elements, confident asymmetric layout"
