# Case study — NorthShutter (fictional AR headset × GTA VI concept)

Eight ChatGPT-generated 1672×941 website mockups plus a production playbook, built into a real hero in Oct 2026. Used here to show what the method keeps and what it corrects. Style blend: `cyberpunk` (atmosphere) + `luxury` (restraint) + `cinematic` (immersion).

## What worked, and why

| Decision | Why it works |
|---|---|
| **One anchor image first**, every other screen generated from it | Product shape, type rhythm and grade stay consistent; eight screens read as one site at eight scroll positions, not eight Dribbble shots |
| **Seduce → explain → convert** (price only in the last section) | Desire is built before the ask; the price lands as a reward, not an interruption |
| **One focal object per frame** at ~60 % of width | Instant hierarchy; nothing competes with the product |
| **Constant copy anchor**: every headline at the same left gutter and height | The eye knows where to return — the cure for "text placed randomly" |
| **Calm UI, saturated imagery** | Near-black/steel UI lets the neon reflections carry the colour; 60-30-10 holds in the chrome while the art is free |
| **One sans family doing most work**, light extended display + neutral text | Premium tech posture without typographic noise |
| **One coral CTA style** | The accent means "act"; nothing else uses it |
| **Visual metaphor from the product**: the world inside the visor becomes the world outside | Every section transition has a reason (reflection → portal → world) |

## What didn't, and why

| Problem in the mockups | Why it fails | Correction |
|---|---|---|
| "Reserve Now / Pre-order" on 7 of 8 screens | Contradicts the brief's late price; sells before seducing | "Discover" early; preorder only in the final section |
| 7–9 text clusters per frame (nav, eyebrow, headline, body, CTA pair, partner logos, feature strip, launch date, scroll cue) | Eye visits all four corners; reading path zig-zags | One copy column + one aligned bottom row |
| The same 3-column feature strip on 4–5 screens | Repetition reads as filler; adds words, no new claim | Once, in the section it belongs to |
| Handwritten script lettering | A third typeface; tone clash with the clean sans | Artwork only, never UI |
| Blue accent word in every headline; gradient text in one | Works once; formula by the eighth time; gradient text is a tell | Keep one accent device, drop gradient text |
| "Watch the Reveal 02:17" buttons with no video | Fake controls destroy trust | Only render controls that work |
| Six tech callouts + four feature columns on the tech screen | Overload; specs invented | ≤ 3 callouts, labelled speculative |
| Headset geometry drifts between screens | Breaks product credibility | Silhouette lock + product master renders |
| Third-party logos (Rockstar, GTA) baked in | Trademark risk | Text-only fictional line + disclosure |

## Process lessons encoded in Darkroom

- Concept images are layout goals; runtime needs clean plates, product masters, frames.
- Measure, don't eyeball: font chosen by rendering six OFL candidates beside the reference crop.
- Build the still, screenshot, compare side by side, fix the top 3–5 gaps, repeat (7 fixes over 4 rounds for the hero).
- Brief beats screenshot beats playbook beats generic skill taste.
