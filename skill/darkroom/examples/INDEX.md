# Examples: 100 requests with full build specs

Each file is one website Darkroom can make: **Say this** is a request a person could type after `/darkroom` (change the details to your own business), and **Build spec** is the precision Darkroom writes before coding (`templates/BUILD_SPEC.md`, `references/spec-precision.md`).

**For Claude:** before writing a project's `BUILD_SPEC.md`, read the **two closest** examples in full (motion level first, then look, then surface and platform) and match their density: every element with a full style line, every motion with trigger, delay, duration, easing and from → to, real copy, a "Do not" list last. Borrow structure and precision, never their copy, brand, layout or media plan. All brands, people and places of business are fictional; figures marked TEMP are examples, not facts.

**Status:** written 2026-10-28; **none has been built yet**, so the values are Darkroom defaults, not measured results. When one is built and checked (desktop, phone, reduced motion), its header gets "built and verified on <date>". `darkroom spec examples` lints them all (sections, signature, "Do not", placeholders, hotlinks, bare adjectives).
