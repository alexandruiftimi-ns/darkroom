# Prompt template — product master (silhouette lock)

Attach the anchor. One image per view, same chat, same wording, only the view line changes.

```
Product photography of the exact <product> shown in the attached image — identical geometry, proportions, materials, colours, logo placement and details. Studio, seamless neutral mid-grey background, soft key light from upper left, subtle rim light, no reflections of other objects, no text, no props. 2048×2048 px.
View: <front | rear | left three-quarter | right three-quarter | top | detail close-up of <part>>.
Materials: <list from bible>. Details that must match: <silhouette lock list>.
```

Reject any view where a locked detail changes (count lights, straps, logos). These views become the inputs for turntable/video generation and the reference for every later product image.
