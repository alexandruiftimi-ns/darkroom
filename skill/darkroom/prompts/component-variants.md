# Prompt template — component variants / A-B experiment

Isolate ONE variable. Everything else stays word-for-word identical across the variants.

```
Three variants of the <component> for the attached website, shown side by side on one 1672×941 canvas, labelled A, B, C below each in small grey text.
Shared: <content, size, typefaces, colours>.
Variable being tested: <e.g. "button style: A solid accent pill, B outline pill, C text link with arrow">.
Do not change anything else.
```

Use for: type pairings, accent colour, density of a section, nav style, menu card layout, price block. Ask the user which reads best and why; record in APPROVALS.md.
