# Prompt template — section frame (derived from the anchor)

Attach `anchor.png`. Start a fresh chat every ~5 images (long sessions drift).

```
Same website as the attached anchor image: identical product design, typefaces, navigation, grid, margins, colour grade and lighting quality. Only the section content below changes. 1672×941 px.

Section <id> of <N> — claim: "<one sentence>".
Hook: <what changes visually vs the previous section: scale / light / reveal / environment>.
Focal point: <subject> at <x %, y %>.
Headline at the same position as the anchor headline: "<≤ 8 words>".
Body (≤ <budget> words): "<…>".
<CTA: none | secondary "<label>" | primary "<label>">.
<Optional one contextual UI element: describe exactly one, e.g. "one small translucent panel showing <data>">.

Keep: the headline's exact position and size, the nav, the colour roles.
Do not add: a feature strip, partner logos, price (unless this is the conversion section), extra buttons, handwriting, a different product shape.
```

Save as `.darkroom/refs/s<NN>-<id>.png`.
