# Prompt template — direction board (one per direction, identical content)

Use in a **new** ChatGPT chat per direction so directions don't bleed into each other. Same copy in all three; only the direction block changes.

```
Create one high-fidelity desktop website homepage screenshot, 1672×941 px, flat front view, no browser chrome, no device mockup.

Brand: <name> — <one-line offer>.
Audience & mood: <audience>, <three feeling words>, not <the "not like" word>.

Direction "<name>": <one-sentence idea from the subject>.
- Composition: <focal object> at <x %> width on the <side>; headline block in the <left 36 % / top centre>; one primary button directly under the body text; quiet top navigation with <n> links.
- Typography: headline in <letterform description: e.g. light extended geometric sans with double-storey a>, body in <neutral humanist sans>. Only these two typefaces. No handwriting, no script.
- Colour: ground <hex + name>, text <hex>, secondary <hex>, single accent <hex> used only on the primary button. <disciplined: saturated colour only inside the photography | expressive: whole sections in <hues>>.
- Imagery: <subject, light direction, lens, grade, materials>.
- Copy to render exactly: headline "<≤ 8 words>", body "<≤ 30 words>", button "<2–3 words>".

Avoid: more than 3 text groups on screen, logo walls, feature-card rows, gradient text, glowing buttons, purple gradients, stock-photo look, extra badges, fake statistics.
```

Save as `.darkroom/refs/dir-<A|B|C>.png`.
