# Example library — index

Written lessons from real websites (and some mockups) judged **good** or **bad**. No screenshots ship with the skill; each entry is ≤ 60 lines of observations, measured signals and transferable rules. Maintained with `/darkroom learn`; do not edit by hand except to fix errors.

## How commands use it

Load this index, then **only** the entries that match the project — same `category` first, then same `packs` — at most **4 good + 2 bad** per command run. Prefer `confidence: high`. Always load `LESSONS.md` (cross-site rules). Cite entries by slug when they justify a decision ("as in `good/<slug>`"). Entries are evidence, not templates: never reproduce a listed site's layout, imagery or copy.
