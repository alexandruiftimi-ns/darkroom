# Example library — index

Written lessons from real websites (and some mockups) judged **good** or **bad**. No screenshots ship with the skill; each entry is ≤ 60 lines of observations, measured signals and transferable rules. Maintained with `/darkroom learn`; do not edit by hand except to fix errors.

## How commands use it

Load this index, then **only** the entries that match the project, at most **4 good + 2 bad** per command run. Match in this order: (1) the **technique** the project needs, from its motion level and storyboard (a `story` or `hero-effect` page looks up its scroll technique in **By technique** below first); (2) same `category`; (3) same `packs`. When a technique row names a recipe, build the effect from that recipe, not from scratch. Prefer `confidence: high`. Always load `LESSONS.md` (cross-site rules). Cite entries by slug when they justify a decision ("as in `good/<slug>`"). Entries are evidence, not templates: never reproduce a listed site's layout, imagery or copy.

## By technique

Look here first when the project's motion level is `hero-effect` or `story`, or the user names an effect ("like ScrollTide", "scroll animation with frames", "parallax"). Each row lists the entries that do it well, what to build it with, and the one thing that most often goes wrong. Only the 2026-10-27 batch and a few older entries carry `techniques:` tags so far; untagged entries can still match by category.

| Technique | What it is | Good examples | Build with | Watch for |
|---|---|---|---|---|
| `frame-scrub` | a rendered camera move (product flight, assembly, dive) played frame by frame by scroll | seasats, lunarwheel (as frames, not live 3D) | `recipes/scrub-frames.js` + `darkroom media frames --format avif --mobile-width 900` | a phone frame set and coarse-to-fine loading; live claims in HTML over the canvas |
| `video-scrub` | the same move as one seekable video | apple-airpods-pro, icomat | `recipes/scrub-video.js` (all-intra or short-GOP encode) | try this first; switch to frames only when reverse stutters |
| `sprite-clips` | short image-sequence clips per character or object: idle, enter, leave | ribbit, unseen-studio-2025 | `recipes/sprite-clips.js` | still first frame for reduced motion; skip frames on phones |
| `pinned-chapters` | one element stays pinned (product, headline) while chapters scroll past | mana-yerba-mate, seasats, petralithe, inversa, shopify-editions-winter-26, rivian-r2 | `recipes/scene-progress.js` (`--p`) + `position: sticky` | the page must still read top to bottom with JS off |
| `chapter-colour-grade` / `chapter-colour` | the ground colour or time of day changes per chapter | seasats (dawn → sunset), iventions (a pastel per service), porsche-motorsport (red chapters) | `recipes/scene-progress.js` driving a background colour or gradient stop | keep text contrast on every ground |
| `layered-parallax` | flat art cut into layers moving at different speeds | firewatch, petralithe | `recipes/parallax-layers.js` (pointer, scroll or both), or `recipes/scene-progress.js`: each layer `translate3d(0, calc(var(--p) * <depth>px), 0)` | layers need overlap margins so edges never show |
