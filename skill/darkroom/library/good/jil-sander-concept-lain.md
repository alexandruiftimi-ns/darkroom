# Jil Sander concept (LAIN) — good
- **Thesis in one line:** minimalism made loud — an extended wordmark at full width interlocked with a black-and-white portrait.
- **First frame:** (tilted composite) light page, small nav in the corners, the wordmark set across two lines at ~100 % width with a cut-out profile portrait woven between letters; a short lowercase paragraph below; "ABOUT JIL" repeats the trick; a black second page shows the collection grid with vertical category labels and store addresses.

## What works & why
- **Wordmark and portrait interlocked** → principle: one focal point; image and type merged rather than competing (reading-paths.md rule 7) → rule: make the hero one composite object, not headline + picture.
- **Collection grid: photo + vertical label at fixed position** → principle: related items in one grid with labels in one place (reading-paths.md rule 4) → rule: comparable categories share one cell shape and one label position.
- **Strict black/white page alternation** → principle: monochrome mode; cadence by colour-field change (color.md, attention.md) → rule: in a colourless brand, alternate ground colour per chapter for cadence.
## Transferable rules
- Do: one extended face at extreme scale; let photography stay greyscale to match.
- Don't: run lowercase body text justified across the full measure — the hero paragraph exceeds 75ch (typography.md).
