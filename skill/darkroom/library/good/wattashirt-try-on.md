# Wattashirt (Eloqwnt concept) — good
- **Thesis in one line:** a one-tee shop where the product page is a try-on configurator around a single centred model.
- **First frame:** full-height model at ~50 % x; left column: label, "TRY IT ON" title, short body, 01 Colour, 02 Fit; right column: 03 View (front/side/back), 04 Mood thumbnails, then a summary bar with price and GET IT. Eye: title → options left → options right → summary/buy.

| Type | 1 family — neo-grotesque sans; title ~48 px · body ~13 px · tracked caps labels ~11 px; ~4 sizes |

## What works & why
- **Numbered option groups 01–04 split around the model** → principle: zone order = reading order (reading-paths.md rule 3) → rule: number configurator steps so a two-sided layout still reads in one sequence.
- **Running summary ("your look") next to the buy button** → principle: CTA on the path, right after the choice it acts on (reading-paths.md rule 6) → rule: echo the current selection inside the buy cluster.
- **No accent colour at all** — the product (white/black tee) is the only contrast → principle: monochrome mode for catalog surfaces (color.md) → rule: when the product is neutral, keep UI neutral so the garment owns the frame.
## Transferable rules
- Do: centre one product and put every control in numbered groups on the sides.
- Don't: use tiny grey body text on light grey — the mockup's ~13 px body is near the 4.5:1 limit (color.md).

**Open question:** the model is labelled an AI-generated "muse"; generated imagery can break up close (tells.md Proof) — unverified in motion.
