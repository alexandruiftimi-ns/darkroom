# Solarius medtech dashboard (HALO LAB) — good
- **Thesis in one line:** a research dashboard that feels calm — warm neutrals, three clear columns, organic 3D art instead of grey charts.
- **First frame:** left nav (logo, 4 items, nested resources, logout at bottom); centre white column "Today's Plan" with date, meeting row, a report card and two study cards with petal renders; right column "Monthly pinned" list of three bordered items with status lines, then "My learnings" 2×2; far right profile and three round actions.

## What works & why
- **Each column has one job** (navigate / today / pinned / me) → principle: related items in one column, reading order left→right (reading-paths.md rules 3, 4) → rule: a dashboard column is a task, not a widget bucket.
- **Status as icon + word, not colour alone** ("Deadline is today", "Accepted") → principle: UI state ≥ 3:1 and not colour-only (color.md rule 3) → rule: pair every status colour with a glyph and a label.
- **Illustrative renders only on the "content" cards** → principle: separate media palette from UI palette (color.md rule 1) → rule: put imagery in content tiles and keep list items plain.
## Transferable rules
- Do: warm neutral ground + black ink for a medical tool that must feel calm.
- Don't: render list items as the same bordered card at the same padding (tells.md Structure) — the pinned list already flirts with it.

**Open question:** no actual data visualisation is shown; it's a planner more than an analytics view, despite the shot title.
