# Serus — good
- **Thesis in one line:** a privacy and OSINT AI that opens on its own input — a prompt box under one typed serif sentence.
- **First frame:** animated dot logo centred at ~50 % / 26 %, typed serif line under it (mobile: "I can remove your data"), large prompt box at ~50 % / 45 %, privacy note below, grey client logos at the bottom; cookie card bottom-left.

## What works & why
- **The prompt box is the hero** with a typed example query → principle: one focal point; the product is the CTA (reading-paths.md rules 6–7) → rule: if the product is an input, the first frame is that input with a live example, not a description of it.
- **Serif for one job only** — the typed sentence is Reckless, everything else Geist → principle: 2 families with distinct roles (typography.md) → rule: give the display serif a single voice line and keep all UI in the sans.
- **Device still lifes tinted to the UI accent** — phone on a lilac tray, laptop on a blue-grey sculpted table → principle: media and UI palettes agree (color.md) → rule: shoot product in props tinted to the one accent so photo and buttons read as one palette.
